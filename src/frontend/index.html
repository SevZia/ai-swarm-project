Cổng 3306 trên máy chủ VPS 31.220.60.199 đã mở và tiếp nhận kết nối, nhưng MySQL trả lời: Access denied for user 'hdd_user'@'...'. Do tài khoản hdd_user trên VPS chỉ cho phép truy cập cục bộ (localhost), chưa cấp quyền truy cập từ IP ngoài mạng.

CREATE USER IF NOT EXISTS 'hdd_user'@'%' IDENTIFIED BY '/Vj)mQbEz&Bdxlx+,OU1';
GRANT ALL PRIVILEGES ON hdd_appsheet.* TO 'hdd_user'@'%';
FLUSH PRIVILEGES;
